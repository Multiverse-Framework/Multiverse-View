# Multiverse View

A web-based tool for visualizing [USD](https://openusd.org/) scene graphs using [threejs](https://threejs.org/). It also allows for the annotation of semantic labels and downloading of the labeled scenes.

![image](https://github.com/Multiverse-Framework/Multiverse-View/assets/64316740/e92dc581-8379-4467-a762-a06d02883f80)

## Installation

```bash
wget https://nodejs.org/dist/v20.12.0/node-v20.12.0-linux-x64.tar.xz
tar -xvf node-v20.12.0-linux-x64.tar.xz
export PATH=$PATH:${PWD}\node-v20.12.0-linux-x64/bin
npm install
npm run dev
```

## Run

```bash
export PATH=$PATH:${PWD}\node-v20.12.0-linux-x64/bin
npx vite
```
